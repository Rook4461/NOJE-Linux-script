# NOJE-Linux-script
Linux script for OK Cup and CyberPatriot practice.

## Script

- `okcup_cyberpatriot.sh`

## Usage

```bash
chmod +x okcup_cyberpatriot.sh
./okcup_cyberpatriot.sh --audit
sudo ./okcup_cyberpatriot.sh --harden
```

## Options

- `--audit`: show firewall, SSH, and password policy settings
- `--harden`: apply a baseline hardening profile
- `--help`: show help
